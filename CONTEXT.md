# web-cv

Le CV en ligne de Colas Durcy : une page unique qui présente son parcours à des recruteurs, et le
document qu'ils peuvent emporter.

## Langage

### La chaîne du CV

Trois maillons, dans cet ordre. Chacun découle du précédent, jamais l'inverse.

**Doc CV** :
Le document Google Docs où le CV s'écrit. C'est **la source de vérité** : le seul maillon éditable,
et le seul endroit où une correction de contenu a le droit de commencer. Il en existe deux
exemplaires, un par langue.
_Éviter_ : le Doc, la source, le Drive.

**CV PDF** :
L'export figé du Doc CV, distribué en téléchargement depuis le Site CV. Il ne se modifie pas, il se
régénère. Un CV PDF qu'on retouche directement est un CV PDF qui a divergé.
_Éviter_ : CV, résumé, plaquette, le PDF.

**Site CV** :
La page unique déployée, écrite pour être parcourue à l'écran par un recruteur. Son contenu factuel
reflète le Doc CV.
_Éviter_ : portfolio, site perso, « le CV » employé seul.

Le Site CV et le CV PDF doivent énoncer les mêmes faits — dates, intitulés, expériences. Ils ne les
présentent pas de la même façon : le Site CV est parcouru à l'écran, le CV PDF est imprimé, relu en
entretien et lu par des filtres automatiques. Une divergence de faits est un défaut ; une divergence
de forme n'en est pas un.

Une copie locale du Doc CV peut exister sur disque, au format `.docx`. C'est une **sauvegarde**, pas
un maillon : elle protège d'une perte de compte, elle ne fait jamais foi.

### Les versions du document

**CV généralisé** :
La version du CV qui ne vise aucune offre en particulier. C'est la seule que le Site CV distribue,
et la raison pour laquelle il change peu.
_Éviter_ : CV par défaut, CV standard.

**CV adapté** :
Une version retaillée pour une candidature précise, échangée directement avec l'interlocuteur. Elle
ne passe jamais par le Site CV et n'est pas versionnée ici.
_Éviter_ : CV personnalisé, CV ciblé.

### La publication

**Publication atomique** :
La règle selon laquelle les deux langues du CV PDF partent ensemble ou pas du tout. Elle existe
parce qu'une version qui décroche silencieusement ne se remarque pas : c'est le mode de panne qui a
laissé un CV périmé en ligne pendant six mois.
_Éviter_ : synchro, déploiement du CV.
